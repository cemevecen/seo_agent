More ↗
  • CrUX = real users. Mobile/desktop numbers here are field data from the last ~28 days, not lab tests. A deploy will not show up instantly.
  • URL count ≠ traffic. There can be many “Poor URLs”, but pages with no clicks barely affect ranking. Fix high-traffic templates first.
  • LCP / INP / CLS are separate jobs. LCP is mostly image+TTFB; INP is JS weight; CLS is unsized media/ads. The same “Poor” row can have different root causes.
  • AMP ≠ a speed guarantee. The AMP tab lists validation/compatibility issues. A URL can be “good” on AMP while CWV is poor on the canonical (and vice versa).
  • Custom JS is forbidden on AMP. “Custom JavaScript is not allowed” → remove the script from the AMP copy or move it to an AMP component. JS can remain on canonical HTML.
  • Small image warning. “Image is smaller than recommended” is usually a warning band; it is not broken AMP, but fix width-height/srcset for LCP/quality.
  • Scan delay. GSC data can lag behind the console. If the chart is empty, check the last scan time first.
  • Priority order. 1) High-click Poor LCP/INP templates · 2) AMP validation (index-loss risk) · 3) Needs improvement bulk cleanup · 4) cosmetic AMP image warnings.
