  • CrUX = gerçek kullanıcı. Bu paneldeki mobil/masaüstü sayılar lab testi değil; son ~28 günlük alan verisidir. Anlık deploy etkisi hemen görünmez.
  • URL sayısı ≠ trafik. “Kötü URL” çok olabilir ama tıklamasız sayfalar sıralamayı az etkiler. Önce yüksek trafikli şablonları düzelt.
  • LCP / INP / CLS ayrı iş. LCP çoğunlukla görsel+TTFB; INP JS ağırlığı; CLS boyutsuz medya/reklam. Aynı “Poor” satırı farklı kök neden demektir.
  • AMP ≠ hız garantisi. AMP sekmesi validation/uyumluluk sorunlarını listeler. Bir URL AMP’te “iyi” olsa bile canonical’da CWV kötü olabilir (ve tersi).
  • Custom JS AMP’te yasak. “Custom JavaScript is not allowed” → AMP kopyasından script’i kaldır veya AMP bileşenine taşı. Canonical HTML’de JS kalabilir.
  • Küçük görsel uyarısı. “Görüntü boyutu önerilen boyuttan küçük” genelde uyarı bandıdır; kırık AMP değildir ama LCP/kalite için width-height/srcset düzelt.
  • Tarama gecikmesi. “Tara” Mac köprü ile GSC’yi çeker; GSC’nin kendi güncelleme gecikmesi + köprü süresi üst üste binebilir. Grafik boşsa önce son tarama zamanına bak.
